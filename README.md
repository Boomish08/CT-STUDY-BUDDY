# CT Study Buddy

A GenAI study assistant for Computer Technology students, built by **Boomish V** (B.Sc Computer Technology, KPR College of Arts Science and Research).

## Features
- **Explain**: step-by-step explanations with analogies and code examples
- **Quiz me**: one multiple-choice question at a time with scoring
- **Summarize notes**: summary, key terms and likely exam questions
- Runs fully in the browser (HTML, CSS, JavaScript) and calls the Google Gemini API
- Your API key is stored only in your own browser and is never committed to this repo

## Tech
HTML5 · CSS3 · Vanilla JavaScript · Google Gemini API · GitHub Pages · GitHub Actions

## Run locally
Open `index.html` in a browser, paste a Gemini API key under **API settings**, and start chatting.

## Deploy
Push to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the site to GitHub Pages.
